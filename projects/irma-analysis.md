> Portfolio case study based on professional project experience. This page describes the product and contribution at a high level; it does not contain client source code or confidential implementation details.

## Overview

IRMA Analysis is a risk analysis platform for US healthcare institutions to benchmark medical-device compliance against federal security standards.
